# Facit

Mellanleden rättas på värde. Decimalformen får lämnas tom. Facit visar Joachims form.

**1** a) 41/50 = 82/100 = 82 %  b) 12/400 = 3/100 = 3 %  c) 21/35 = 3/5 = 0,6 = 60 %

**2** 49/700 = 7/100 = 7 %

**3** 17 + 8 = 25 elever. 8/25 = 32/100 = 32 %

**4** 600 − 376 − 200 = 24 kr. 24/600 = 4/100 = 4 %

**5** a) 24/60 = 2/5 = 0,4 = 40 %  b) 5 m = 50 dm. 9/50 = 18/100 = 18 %

**6** Alva: 15/20 = 3/4 = 0,75 = 75 % (även 15/20 = 75/100 = 75 %). Kim: 37/50 = 74/100 = 74 %. Svar: A

**7** 9 + 4 = 13 matcher. 13/25 = 52/100 = 52 %

**8** C. Felalternativen är vanliga elevfel:
- A: fel helhet. Ida delar pojkarna med flickorna (delen genom resten) i stället för med alla 25 elever.
- B: Omar förlänger bara nämnaren (25 · 4 = 100) men inte täljaren.
- D: Leo skriver antalet pojkar (delen) som procent.
