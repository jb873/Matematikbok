# Facit

Likvärdiga svar godkänns, till exempel 0,7 för 0,70. I kedjorna rättas mellanleden på värde.

**1** a) 3/5 = 0,6 = 60 %  b) 19/100 = 0,19 = 19 %

**2** a) 0,75 = 75 %  b) 0,7 = 70 %  c) 0,67 = 67 %  d) 0,09 = 9 %

**3** a) 22/55 = 2/5 = 0,4 = 40 %  b) 16/64 = 1/4 = 0,25 = 25 %  c) 36/48 = 3/4 = 0,75 = 75 %

**4** a) 7/25 = 28/100 = 0,28 = 28 %  b) 11/50 = 22/100 = 0,22 = 22 %  c) 17/50 = 34/100 = 0,34 = 34 %

**5** a) 48/600 = 8/100 = 0,08 = 8 %  b) 99/1100 = 9/100 = 0,09 = 9 %  c) 189/900 = 21/100 = 0,21 = 21 %

**6** a) 65 % = 65/100 = 13/20 = 0,65  b) 32 % = 32/100 = 8/25 = 0,32  c) 70 % = 70/100 = 7/10 = 0,7

**7** a) 42 %  b) 60 %

**8** a) A  b) C  c) C  d) B  e) A

Felalternativen i uppgift 8 är vanliga elevfel: decimalen läses som procent (0,6 = 6 %, 0,08 = 80 %), nämnaren läses som procent (1/4 = 4 %), siffrorna skrivs ihop (1/4 = 14 %, 3/5 = 35 %) och procent flyttas ett steg för lite (5 % = 0,5).
