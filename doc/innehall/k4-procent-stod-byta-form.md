# Byta form

Ett tal kan skrivas på tre sätt: i bråkform, i decimalform och i procentform. Procent betyder hundradelar, så 35 % är detsamma som 35/100.

## 1 Förlänga till hundradelar

Används när nämnaren är 20, 25 eller 50 och bråket inte går att förkorta.

- Ta reda på hur många gånger nämnaren går i 100.
- Multiplicera täljaren och nämnaren med det talet.
- Antalet hundradelar är procenttalet.

Exempel

7/20 = 35/100 = 35 %

13/25 = 52/100 = 52 %

## 2 Förkorta till hundradelar

Används när nämnaren är ett jämnt hundratal, från 200 till 1 200.

- Ta reda på hur många hundratal nämnaren är.
- Dela täljaren och nämnaren med det talet.
- Antalet hundradelar är procenttalet.

Exempel

8/200 = 4/100 = 4 %

72/300 = 24/100 = 24 %

## 3 Förkorta till enklaste form

Används när bråket går att förkorta till ett standardbråk.

- Hitta det största tal som både täljaren och nämnaren går att dela med.
- Dela täljaren och nämnaren med det talet.
- Skriv bråket i decimalform.
- Skriv decimaltalet i procentform.

Exempel

12/16 = 3/4 = 0,75 = 75 %

6/30 = 1/5 = 0,2 = 20 %

## 4 Byta mellan former

**Från bråk till procent**
- Skriv bråket i decimalform.
- Multiplicera decimaltalet med 100. Kommat flyttas två steg åt höger.
- Skriv procenttecknet efter talet.

**Från procent till bråk och decimalform**
- Skriv procenttalet som hundradelar.
- Förkorta till enklaste form.
- Skriv bråket i decimalform.

Exempel

35 % = 35/100 = 7/20 = 0,35

60 % = 60/100 = 3/5 = 0,6

**Standardbråken**

| Bråkform | Decimalform | Procentform |
|---|---|---|
| 1/2 | 0,5 | 50 % |
| 1/4 | 0,25 | 25 % |
| 3/4 | 0,75 | 75 % |
| 1/5 | 0,2 | 20 % |
| 1/10 | 0,1 | 10 % |
| 1/3 | ≈ 0,33 | ≈ 33 % |
