## Steg 1: upprepad addition blir koefficient

Förståelse: när samma term adderas flera gånger kan summan skrivas som en produkt, x + x + x = 3 · x = 3x. Talet framför variabeln kallas koefficient. Uppgift 5 visar att det förenklade uttrycket har samma värde som det långa.

Förlagor: E s. 138 teori (x + x + x = 3x, koefficient) · A 2092 · kap 3.3 teori (5y = y + y + y + y + y, b + h + b + h = 2b + 2h) · E exempel (3x + x = 3x + 1x) · omkrets som ingång [2.4 teori].

Hakparenteser [förlaga] är interna och visas inte för eleven.

### Blad 1A

1. Skriv summan som ett kortare uttryck.
a) x + x + x = ___
b) y + y + y + y + y = ___
c) a + a = ___
[E s. 138 teori, kap 3.3 teori]

2. Välj det uttryck som betyder samma sak.
a) 4x:   A. x + 4   B. x + x + x + x   C. 4 + 4 + 4 + 4
b) 2y:   A. y + y   B. y + 2   C. 2 + 2
c) 3b:   A. 3 + b   B. b + 3   C. b + b + b
[kap 3.3 teori]

3. Förenkla uttrycket.
a) x + x + 2x
b) y + 2y
c) 3a + a
[A 2092, E exempel]

4. Fyll i ett uttryck för omkretsen och förenkla det.
a) (Figur: en liksidig triangel där varje sida är a cm.) ___
b) (Figur: en kvadrat där varje sida är s cm.) ___
c) (Figur: en rektangel med sidorna b cm och h cm.) ___
[kap 3.3 teori, 2.4 teori]

5. a) Beräkna x + x + x när x = 6.
b) Förenkla först x + x + x och beräkna sedan värdet när x = 6.
[E 79]

### Blad 1B

1. Skriv summan som ett kortare uttryck.
a) z + z + z + z = ___
b) x + x + x + x + x + x = ___
c) b + b + b = ___
[E s. 138 teori, kap 3.3 teori]

2. Välj det uttryck som betyder samma sak.
a) 5y:   A. y + 5   B. 5 + 5 + 5 + 5 + 5   C. y + y + y + y + y
b) 3x + x:   A. 3x   B. 4x   C. 4 + x
c) y + 2y + y:   A. 4y   B. 3y   C. 2y + 2
[kap 3.3 teori, E exempel]

3. Förenkla uttrycket.
a) 2x + x + x
b) a + 3a + 2a
c) 4y + y
[A 2092, E exempel]

4. Fyll i ett uttryck för omkretsen och förenkla det.
a) (Figur: en liksidig triangel där varje sida är 2x cm.) ___
b) (Figur: en rektangel med sidorna 2a cm och a cm.) ___
c) (Figur: en rektangel med sidorna x cm och y cm.) ___
[kap 3.3 teori, 2.4 teori, C 60]

5. a) Beräkna y + y + y + y när y = 7.
b) Förenkla först y + y + y + y och beräkna sedan värdet när y = 7.
[E 79]
